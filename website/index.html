Everything you copied.
Nothing you wanted kept private.

Dark Clipboard remembers text, links, code, images and files you copy, and finds them again as you type. It runs on your PC, with no account and no telemetry. By default nothing leaves it; the only exceptions are opt-in: the update check and translate in place with your own Anthropic key.

Free software under GPLv3, written in Rust. macOS and Linux are planned, not available yet.

Search as you type

Full-text search over everything you kept, with filters for text, links, code, images, files, colours, dates and apps.

Pin what you reuse

Pinned clips stay on top and never expire. Star favorites, sort them into collections, add tags and a note.

Copy as…

Trim, change case or line endings, pretty-print or minify JSON, encode URLs or Base64, strip HTML. The original never changes.

Paste back

Enter copies. Ctrl+Enter pastes into the app you came from, if you turn it on.

Backup and export

Back up the whole history to a file, restore it, import and export collections. Masked clips, which may hold a secret, are left out.

English and Vietnamese

The whole interface in both languages, with room for Vietnamese diacritics in every row.

Translate in place

Type, press Ctrl+Alt+T, and the selection, or the whole field when nothing is selected, is translated in place: Vietnamese into English, anything else into Vietnamese (or always one language, as you choose in Settings). It uses your own Anthropic key, is off by default and asks once before turning on. Excluded apps, private-marked and secret-looking text are never sent. Windows.

It checks before it reads.

When something is copied, Dark Clipboard first looks only at the list of formats and the app that copied it. If the copy is marked private, the content is never read at all.

A copy happens

Windows tells Dark Clipboard that the clipboard changed.

Look, don't read

It reads the format list and the source app. Not the text, not the image.

Private? Skip.

Private markers, an excluded app, Pause or Private mode: the copy is skipped unread.

Kept locally

Otherwise it is stored on this PC. Text that looks like a password, key or card number is not stored by default.

Protections you cannot turn off

  • Windows privacy markers. Copies that ask to stay out of clipboard history, cloud sync or clipboard monitors.
  • Password managers. Their privacy markers are always respected. KeePassXC, KeePass 2, Bitwarden and 1Password are also on the built-in excluded list, which you can edit after a confirmation.
  • Darkshot. Screenshots Darkshot marks private are never stored.
  • Your own rules. Exclude more apps, pause for a while, or switch to Private mode from the tray.

Verified by hand: Darkshot 0.6.0 private copies were not stored. KeePassXC 2.8.0 privacy markers were seen on its copies. KeePass 2, Bitwarden and 1Password are not yet verified.

Get the alpha

Version 0.3.0 for Windows 11 x64: a single exe, no installer, nothing to uninstall.

  1. Download dark-clipboard-0.3.0-windows-x64.zip and SHA256SUMS.txt from the release page.
  2. Check the hash in PowerShell (right). It must match the line for the zip.
  3. Unzip and start dark-clipboard.exe. It sits in the notification area; press Ctrl+Shift+V.
  4. The welcome explains what is never captured. Nothing is captured until you press Start.
Release 0.3.0 on GitHub Changelog
PowerShell
# in the folder with both files
Get-FileHash .\dark-clipboard-0.3.0-windows-x64.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt

The exe is not signed, so SmartScreen may say "Windows protected your PC". Run it only after the hash matches, then choose More info and Run anyway. Smart App Control may block it entirely.

Prefer to build it? cargo build --release -p dark-clipboard with a recent stable Rust on Windows 11.
