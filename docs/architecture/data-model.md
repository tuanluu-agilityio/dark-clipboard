# Data Model

Status: Phase 0, 2026-11-22. Storage decision: ADR-0003. JSON Schemas: `docs/architecture/schemas/`. Examples: `docs/architecture/examples/` (validated by `scripts/validate-schemas.mjs`).

## 1. Principles

- **Versioned at every boundary.** Each JSON document carries `schema_version` (integer). The database carries `PRAGMA user_version`. Settings carry `settings_version`.
- **The DB is the store, JSON is the interface.** JSON shapes are what the Application API, CLI and MCP return. The SQL layout may differ and may change through migrations without changing JSON versions.
- **Content is separated from metadata.** Small text is inline in SQLite; large payloads and all images are blobs on disk, addressed by SHA-256. This lets metadata-only consumers (MCP scope `clips:read-metadata`) never touch content.
- **No secrets at rest by design.** Concealed/excluded content never reaches storage. Detected-sensitive content is dropped or kept masked for a short time, per the privacy policy.

## 2. Identifiers and time

- `ClipId`, `CollectionId`, `TagId`: UUID v7 text (time-ordered, sortable, generated by the app). Crate: `uuid` with `v7` feature (one small dependency, justified by sort order and collision-free merges for P3 sync).
- Timestamps: RFC 3339 UTC strings in JSON; INTEGER Unix milliseconds in SQLite. The core receives time through a `Clock` trait (Darkshot's `LocalTime` pattern: core never reads the OS clock directly).

## 3. Entities

### Clip
| Field | Type | Notes |
|---|---|---|
| `id` | ClipId | |
| `schema_version` | 1 | |
| `kind` | ClipType | primary kind |
| `preview` | string ≤ 512 chars | plain-text preview; for images `"Image 1920×1080"`; for files the first names. For `sensitivity.level = masked` the preview is masked (`sk-…••••`) |
| `representations` | Representation[] | each stored format |
| `content_hash` | hex SHA-256 | dedupe key (§5) |
| `size_bytes` | integer | sum of representation sizes |
| `created_at`, `last_copied_at`, `last_used_at` | time | `last_used_at` = last time copied back by the user |
| `copy_count`, `use_count` | integer | |
| `pinned` | bool | pinned clips are exempt from retention and sorted first |
| `pin_order` | integer? | manual order among pinned |
| `source` | ClipboardSource? | absent if unknown |
| `sensitivity` | `{ level: none | masked, categories: SensitiveCategory[] }` | never contains matched text |
| `note` | string? (P1) | user note, ≤ 4,000 chars |
| `tags` | TagRef[] (P1) | |
| `collections` | CollectionRef[] (P1) | includes system collection `favorites` |
| `expires_at` | time? | set for masked/sensitive clips or by retention rule |
| `metadata` | ClipMetadata | |

### ClipType
`text` · `rich_text` (has HTML or RTF besides plain) · `url` (text that is a single absolute URL) · `color` (single hex/rgb colour) · `code` (heuristic, P1) · `image` · `files`.
Rules live in `darkclip-core::classify`, with unit tests. `url`, `color`, `code` are text subtypes; the plain text representation is always present for them.

### Representation
| Field | Notes |
|---|---|
| `mime` | normalized MIME: `text/plain;charset=utf-8`, `text/html`, `text/rtf`, `image/png`, `text/uri-list` |
| `platform_format` | original name, e.g. `CF_UNICODETEXT`, `public.html` (diagnostics; used to restore faithfully) |
| `size_bytes` | |
| `storage` | `inline` (≤ 64 KiB text) or `blob` |
| `blob_sha256` | for blob storage |
| `width`, `height` | images |

Images are normalized to PNG on capture (DIB → PNG on Windows, TIFF → PNG on macOS). The original format is not kept in P0, which saves space; restore writes PNG plus the platform's native bitmap format.

### ClipMetadata
`char_count`, `line_count`, `language_hint` (P1), `file_count`, `image_thumb_sha256`, `truncated` (bool: text exceeded the 1 MiB cap and was cut, so restoring yields the truncated text; the UI shows a badge).

### ClipboardSource
| Field | Notes |
|---|---|
| `app_id` | stable id: Windows exe name lowercased (`keepassxc.exe`); macOS bundle id (`com.apple.Safari`); Linux desktop file id or `/proc/<pid>/exe` basename |
| `app_name` | display name if known |
| `platform` | `windows` · `macos` · `linux-x11` · `linux-wayland` |
| `confidence` | `owner` (clipboard owner process, Windows/X11) · `frontmost` (heuristic) · `declared` (`org.nspasteboard.source`) |

Window titles are **not** part of the model.

### Collection (P1)
`id`, `schema_version`, `name` (≤ 80), `kind` (`user` | `system`), `system_key` (`favorites` for the built-in Favorites collection), `color` (optional), `created_at`, `updated_at`, `clip_count` (derived), `sort` (`manual` | `recent`).
**Favorite** is modelled as membership in the system collection `favorites`, so one mechanism covers both. Favorites are exempt from retention like pinned clips.

### Tag (P1)
`id`, `name` (lowercase, ≤ 40, `[\p{L}\p{N}_-]+`), `created_at`. Many-to-many with clips.

### RetentionPolicy
`max_items` (default 1,000; 0 = unlimited), `max_age_days` (30), `max_storage_mb` (500), `keep_pinned` (true, fixed), `keep_favorites` (true), `sensitive_ttl_seconds` (120, used only when sensitive handling = `store_masked`), `image_max_mb` (20), `text_max_kb` (1,024).
Eviction order: expired first, then oldest `last_copied_at` among non-pinned, non-favorite clips, until all limits hold.

### PrivacyPolicy
`capture_enabled`, `mode` (`normal` | `paused` | `private`), `paused_until`, `excluded_apps` (list of `{ app_id, platform, name }`), `capture_kinds` (subset of ClipType), `sensitive_handling` (`drop` default | `store_masked` | `store`), `sensitive_categories_enabled`, `respect_os_markers` (always true; read-only in UI), `capture_primary_selection` (Linux, default false).

### AiPermission (P2)
`client_id` (e.g. `claude-code`), `display_name`, `granted_at`, `scopes` (`clips:read-metadata`, `clips:read-content`, `collections:read`, `collections:write`, `clips:write-organization` (notes, tags, pin), `clipboard:write`, `export`), `collection_filter` (optional allow-list of collections), `include_sensitive` (always false in P2; not grantable), `expires_at`, `revoked_at`.

### OperationAudit (P2)
`id`, `at`, `actor` (`ui` | `cli` | `mcp:<client_id>`), `operation` (tool/command name), `result` (`ok` | `denied` | `error`), `items` (count), `clip_ids` (ids only), `error_code`. **No content, no query strings** (a search query can itself be sensitive). Kept 90 days, max 10,000 rows.

## 4. SQLite layout (version 1)

```sql
PRAGMA journal_mode = WAL;
PRAGMA foreign_keys = ON;
PRAGMA user_version = 1;

CREATE TABLE clips (
  id TEXT PRIMARY KEY,
  kind TEXT NOT NULL,
  preview TEXT NOT NULL,
  content_hash BLOB NOT NULL UNIQUE,          -- 32 bytes
  size_bytes INTEGER NOT NULL,
  created_at INTEGER NOT NULL,
  last_copied_at INTEGER NOT NULL,
  last_used_at INTEGER,
  copy_count INTEGER NOT NULL DEFAULT 1,
  use_count INTEGER NOT NULL DEFAULT 0,
  pinned INTEGER NOT NULL DEFAULT 0,
  pin_order INTEGER,
  source_app_id TEXT, source_app_name TEXT, source_platform TEXT, source_confidence TEXT,
  sensitivity_level TEXT NOT NULL DEFAULT 'none',
  sensitivity_categories TEXT,                -- JSON array of category names
  note TEXT,
  expires_at INTEGER,
  meta TEXT NOT NULL DEFAULT '{}'             -- ClipMetadata JSON
);
CREATE INDEX clips_recent ON clips(pinned DESC, last_copied_at DESC);
CREATE INDEX clips_expiry ON clips(expires_at) WHERE expires_at IS NOT NULL;

CREATE TABLE representations (
  clip_id TEXT NOT NULL REFERENCES clips(id) ON DELETE CASCADE,
  ord INTEGER NOT NULL,
  mime TEXT NOT NULL,
  platform_format TEXT,
  size_bytes INTEGER NOT NULL,
  inline_data BLOB,                            -- NULL when stored as blob
  blob_sha256 BLOB,                            -- NULL when inline
  width INTEGER, height INTEGER,
  PRIMARY KEY (clip_id, ord)
);
CREATE INDEX reps_blob ON representations(blob_sha256) WHERE blob_sha256 IS NOT NULL;

CREATE VIRTUAL TABLE clips_fts USING fts5(
  preview, body, note, tags,
  content='', contentless_delete=1,            -- SQLite ≥ 3.43
  tokenize = 'unicode61 remove_diacritics 2'
);
-- rowid mapping: clips_fts.rowid = clip_rowid.rowid
CREATE TABLE clip_rowid (rowid INTEGER PRIMARY KEY, clip_id TEXT UNIQUE NOT NULL REFERENCES clips(id) ON DELETE CASCADE);

-- P1 (migration 2): collections, collection_clips, tags, clip_tags
-- P2 (migration 3): ai_permissions, operation_audit
```

FTS notes:
- `body` indexes up to the first 32 KiB of the plain text representation. Contentless FTS keeps no copy of text beyond the index, so the index holds only tokens.
- `remove_diacritics 2` makes Vietnamese search work without accents ("tieng viet" finds "tiếng Việt"). This is a Darkshot-ecosystem requirement, unit-tested.
- Substring fallback: for queries < 3 chars, or when FTS returns < N results, run `LIKE` on `preview` limited to the 2,000 most recent rows. Trigram tokenizer was considered; it was rejected for P0 because it roughly triples index size.
- Sensitive-masked clips index only their masked preview, never the body.

## 5. Hashing and deduplication

- `content_hash = SHA-256( "dc1\0" || kind || "\0" || canonical_primary )` where `canonical_primary` is:
  - text kinds: the plain text, with CRLF and lone CR normalized to LF (lone CR added by D-020) and the trailing newline kept (a copied line with and without a final newline counts as different on purpose);
  - image: the decoded RGBA pixels plus width/height (so the same image copied as DIB or PNG dedupes). Without decoded pixels, a fallback hashes the encoded bytes behind an `enc ` tag (degraded dedupe; callers should always pass RGBA, D-020);
  - files: the sorted, newline-joined absolute paths.
- Rich text dedupes by its plain text: copying the same paragraph from Word and from a browser yields one clip. The latest representations replace the older ones (`last_copied_at` updated).
- On duplicate: update `last_copied_at`, `copy_count += 1`, and the source; never create a second row.
- Blobs are content-addressed (`blobs/ab/abcdef…`). A blob is deleted when no representation references it (checked inside the same transaction that deletes the clip, then the file is unlinked after commit; orphans are swept at startup).

## 6. Content lifecycle

```
captured → stored (inline/blob) → [copied again: bumped] → [pinned/favorited: retention-exempt]
        → expired (expires_at) or evicted (limits) or deleted (user) → row + FTS + blob removed
```
Deletion is real deletion: `DELETE` plus `PRAGMA secure_delete = ON` for the clips and representations tables (overwrites freed pages), plus unlinking blob files. The UI does not claim forensic erasure (SSD wear levelling), following Darkshot's "never say guarantee" rule.

## 7. Migrations

- Embedded SQL files `migrations/NNNN_name.sql`, applied in a transaction, guarded by `user_version`. No migration framework dependency.
- Before any migration, copy `history.db` to `history.db.pre-vN.bak` (deleted after a successful first run of version N+1).
- Downgrade is not supported: a DB with a newer `user_version` opens read-only with a UI message.

## 8. Backup and restore (P1)

- Backup = SQLite online backup API to `backup-YYYYMMDD.db` + copy of referenced blobs into a zip (`.dcbackup`), with a manifest `{ schema_version, app_version, created_at, clip_count, sha256 per file }`.
- Restore validates the manifest, imports into a temporary DB, runs migrations, then swaps.
- Export collection (P1/P2 `export_collection`) = JSON document matching `export.schema.json` + blobs; sensitive clips are never exported.

## 9. Encryption at rest

P0 relies on OS account protection and full-disk encryption (BitLocker, FileVault, LUKS), and documents this. P2 option: SQLCipher (`rusqlite` feature `bundled-sqlcipher`) with the key in Keychain / DPAPI / Secret Service. Alternative: app-level AEAD on representation payloads only. Decision deferred to a P2 ADR because SQLCipher changes build tooling (OpenSSL or a vendored crypto provider) on all three platforms.

## 10. Settings file

`settings.json`, `settings_version: 1`, containing `privacy` (PrivacyPolicy), `retention` (RetentionPolicy), `shortcuts`, `ui` (`language`, `popup_position`: `cursor` | `center`), `startup` (`launch_at_login`). Written atomically (temp file + rename). Corrupt file → defaults, original renamed `settings.json.corrupt-<ts>` (Darkshot pattern).
