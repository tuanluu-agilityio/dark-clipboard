## Known pitfalls
- **Keys go to a `PopupWindow` while it is open** (D-079): the menu `FocusScope` takes focus in `init` and forwards keys to Rust; tooltips are never `PopupWindow`s; `TooltipLayer` stays the **last child of the window root** (after any new overlay). Elements inside a `PopupWindow` cannot be referenced from outside: drive through properties and `init`.
- **`KitGallery` exists to force compilation** of unused kit components: keep every kit component used there after changing `Menu`.
- **UI icons are never symbol glyphs** (Task 414); scan covers `ui/*.slint` incl. the new file; use `Icon`/`IconName` only.
- **Windows-only code must lint on macOS/Linux** (CI clippy `-D warnings`); `tray_host::current_state()` has both cfg variants, check usage.
- **Software renderer (D-055):** no blur, shadow, gradient; no timer or animation while hidden; the tooltip timer runs only while hovered/focused.
- Single colour source (`theme.rs`); keep `Palette.color-scheme = dark` in `init`; no `unwrap`/`expect`; previews, sources and queries never logged (GC-06); `Debug` of new row/menu types must not print content.
- Run the app only with `--data-dir <temp>` and `--exit-after-ms`; no screenshots, no input simulation, no real clipboard (GC-19).
