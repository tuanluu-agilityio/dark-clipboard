Order of checks: exactly the table in privacy-design §2, steps 1–7. `DarkshotExcluded` takes precedence over `OsConcealed` in the reported reason when all three Darkshot formats are present. `NoCloud` alone does not skip. Text over cap is not skipped; it is truncated (`truncate_text_at`). An image over cap is dropped from the plan; if nothing remains, the result is `Skip(TooLarge)`. Formats `DataObject` / `Ole Private Data` only → `Skip(NothingReadable)`.
