## Known pitfalls
- **Keys go to a `PopupWindow` while it is open** (D-079): the `Select` list needs a `FocusScope` with `init => self.focus()` that forwards keys to Rust; elements inside a `PopupWindow` cannot be referenced from outside (drive by properties and `init`). Tooltips are never `PopupWindow`s; **`TooltipLayer` stays the last child of the window root**, after the dialog and picker.
- **Keep `Palette.color-scheme = dark` in `init`** while any std-widgets remain; `theme.rs` stays the single colour source.
- `KitGallery` forces compile of unused kit components: add every new one.
- UI icons are never symbol glyphs (Task 414): `Icon`/`IconName` only; no emoji or `⚙`-style text.
- Software renderer (D-055): no blur, shadow or gradient; no timer while hidden.
- Windows-only code must lint on macOS/Linux (clippy `-D warnings`).
- Typed app names, paths and clip text never logged (GC-06); no `unwrap`/`expect`; do not touch marker policy code (GC-07).
- Run the app only with `--data-dir <temp>` and `--exit-after-ms`; no screenshots, input simulation or real clipboard (GC-19).
