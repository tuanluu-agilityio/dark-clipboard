Dark Clipboard: UI redesign mockups

Static HTML mockups of the proposed design (not the app). Colours, sizes and icons follow 02-design-system.md; behaviour follows 04-interaction-keyboard.md. Only things Slint's software renderer draws cheaply are used: flat fills, 1 px borders, rounded rectangles, SVG icons. No blur, gradients (except the fake image), or shadows.

The sample clip content is invented. The real app shows English or Vietnamese from darkclip_core::i18n.

1 · Quick Popup: default, and while searching

440 × 520, next to the cursor, with focus in the search box. The header has the search field and four icon buttons: preview, history, settings, close. Esc also closes the popup. Type filters are a single icon segment, and Pinned and Favorites are on the right. The list is split into PINNED and RECENT. The selected row has an accent bar and shows its own quick actions; this replaces the 5-button text footer. The status line shows capture state and two key hints drawn as icons.

2 · Quick Popup with the preview pane open (Vietnamese)

Space, the preview icon, or → opens the preview to the side, widening the popup to 760 px. The list keeps its full height instead of losing 220 px. Placement flips to the left when there is no room on the right. Vietnamese labels are shown here because they are the longest; with icons, the header and status line no longer depend on label width.

3 · History manager: wide window (≥ 1000 px), context menu open

The left side has a sidebar instead of the 180 px filter column. It holds Library views, Types, Collections, Tags and Apps; each group can collapse, and items show counts. The middle has a toolbar (title, search, date filter, select mode) and the list (rows 56 px, two preview lines). On the right is a detail panel with an icon toolbar, preview, facts, tags, note and collections; it replaces the 8-button footer, the 5-button org row and the 3 hint lines. The context menu works from the keyboard (Menu key or Shift+F10).

4 · History manager: narrow window (< 1000 px) with 3 clips selected

Below 1000 px the sidebar shrinks to a 52 px icon rail; the tooltips give names and Ctrl+B expands it. Below 820 px the detail panel becomes a drawer over the list: → or Enter on the preview opens it, and Esc closes it. With 2 or more clips marked, a bulk bar replaces the toolbar title row and shows icons for Pin, Favorite, Add to collection, Tag, Export and Delete. The new minimum width is 640 px (today it is 760).

5 · Settings: Capture & Privacy

Five sections with icons. Each section is a set of cards made of rows: label and short description on the left, the control on the right. The top card makes the current state obvious: one of three capture modes. The "Always protected" card lists the protections that can't be turned off, with a lock and no control, so the user understands them without being able to weaken them (GC-07). Changes are still saved with an explicit Save, but the save bar appears only when something has changed.

6 · Settings: Data & Transfer (new section)

Backup, restore, export and import move here from the long History section. Each destructive action is a row with a secondary button, and a confirmation dialog (unchanged behaviour) opens from it. The data folder and its size are here too. History & Storage (not drawn) keeps the limits, the types to save, and clear/cleanup.
