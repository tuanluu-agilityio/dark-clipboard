Dark Clipboard: app icon options

One icon is used for the .exe, the taskbar and Alt+Tab, the window title bars (History, Settings, Welcome) and the tray. It uses the same tile as Darkshot so the two apps read as one family: a 52/56 rounded square (#202328) with a 1 px #3A3E45 border. The mark inside is in Dark Clipboard's own accent (#7887FF), so the two apps can't be confused. The real .ico is generated by a script with hand-tuned 16, 20 and 24 px versions, as Darkshot does. Here the browser scales a single SVG, so small sizes look softer than they will in the app.
